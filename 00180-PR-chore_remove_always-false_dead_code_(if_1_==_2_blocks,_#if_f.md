## Description

*Opened by [@tyhallcsu](https://github.com/tyhallcsu)* *on Apr 23, 2026*


## What

Removes two categories of dead code that are compile-time unreachable:

### `lara/views/ContentView.swift`
Two `if 1 == 2 { … }` blocks that hide NavigationLinks from the UI:
- **Block 1** (SBX tweaks list): hidden links to `EditorView` (MobileGestalt) and `PasscodeView`
- **Block 2** (Hybrid tweaks list): hidden links to `CCView` (Control Center), `PasscodeView`, and `AppsView` (3 App Bypass)

These views are all reachable via other paths in the UI — the dead blocks only add confusion about what's intentionally disabled vs. what's working.

### `lara/funcs/respringcc.swift`
A 98-line `#if false … #endif` block containing `defaultCarB64` — a base64-encoded Car asset blob that is never referenced anywhere in the codebase.

## Why

- Reduces noise when reading the code — `if 1 == 2` looks like an accident, not intent
- The `#if false` blob in `respringcc.swift` is ~100 lines of unrelated binary data inside an enum that only needs `makeInfoPlist()`
- No behavior change: all removed code was already unreachable at compile time

## Test plan
- [ ] Build succeeds with no new warnings
- [ ] All views previously reachable remain reachable (MobileGestalt, Passcode Theme, Control Center, 3 App Bypass are all still wired in via non-dead code paths)
- [ ] `respringcc.makeInfoPlist()` still works (only the unused `#if false` blob was removed)
