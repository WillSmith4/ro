## Description

*Opened by [@onmyodev](https://github.com/onmyodev)* *on Apr 19, 2026*


Currently the font overwrite function only overwrites to SFUI. While this works for English (and I assume other latin languages), since CJK system UI font is seperated into many other fonts this will not work for these characters. At least that's what I can understand because I know SFUI doesn't have any CJK characters in it

I would imagine that this is not that hard to implement since it's just about overwriting another font based on the language, correct me if I'm wrong :3

I'm not yet aware of any alternatives. At least not on iOS 18.5.
